# Anexos del informe técnico de VIGÍA

Índice de los anexos que complementan el informe principal (`docs/informe.md`). Cada anexo contiene el detalle que el informe resume; el texto proviene de la versión extendida, sin pérdida de contenido.

| Anexo | Archivo | Contenido |
|---|---|---|
| A | `A-protocolo-y-flujos.md` | Formato canónico detallado, notas de los 5 pasos, casos de la verificación de historial, tabla de manejo de llaves, parámetros y cotas de Argon2id, modelo de datos, API, dashboard y CLI |
| B | `B-amenazas-detallado.md` | Modelo de atacante y supuestos, qué cubre TLS, tabla completa de amenazas con riesgo residual, lectura de conjunto y tabla completa de limitaciones |
| C | `C-revision-seguridad.md` | Tests por archivo, hallazgos completos de las dos rondas de revisión independiente, análisis estático con falsos positivos y tabla de lo logrado frente al diseño |
| D | `D-reproducir.md` | Puesta en marcha, tests y análisis estático, scripts de TLS y de la BD robada |
| - | `informe-completo.md` | Versión extendida e íntegra del informe anterior a la condensación (con los diagramas Mermaid embebidos) |

Los diagramas (fuentes `.mmd` y PNG) están en `docs/diagramas/`. Las referencias "sección N" dentro de los anexos remiten al informe principal.
